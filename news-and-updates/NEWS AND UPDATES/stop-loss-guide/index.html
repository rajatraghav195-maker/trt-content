Stop Loss Kya Hai?

Stop loss ek pre-defined price level hai jahan tum automatically exit kar lete ho — to limit your loss.

Simple definition: > Stop loss = "Agar price yahan tak pahunche toh mujhe bahar nikal do." Ye tumhara insurance hai.

Example:
• Tumne Reliance ₹2,500 pe kharida
• Stop loss: ₹2,450 (2% below entry)
• Agar Reliance ₹2,450 gir jaaye → Auto sell → Loss limited to ₹50/share

Without stop loss: Reliance ₹2,200 tak gira → ₹300/share loss (6x worse)

Types of Stop Loss

1. Fixed Stop Loss:
• Entry price se X% neeche
• Example: 2% below entry
• Best for: Beginners

2. Support-Based Stop Loss:
• Support level se thoda neeche
• Example: Support at ₹2,450 → SL at ₹2,430
• Best for: Swing traders

3. ATR-Based Stop Loss:
• 2× ATR from entry
• ATR = Average True Range (stock's average daily movement)
• Best for: Advanced traders

4. Trailing Stop Loss:
• Moves with price (locks in profit)
• Price upar jaaye → SL bhi upar jaaye
• Price neeche jaaye → SL same rahe
• Best for: Trend following

How to Set Stop Loss

Rule 1: Before Entry

Stop loss PEHLE decide karo — trade lene ke baad nahi.

Rule 2: Based on Chart, Not Emotion

"₹100 ka loss sah sakta hoon" → GALAT "Support ₹2,450 pe hai, SL ₹2,430 rakhao" → SAHI

Rule 3: Not Too Tight

SL bahut paas rakhoge → jaldi trigger hoga → unnecessary loss

Rule 4: Not Too Loose

SL bahut door rakhoge → bahut bada loss hoga trigger pe

Rule 5: Never Remove Stop Loss

"SL hata deta hoon, wapas aa jayega" → SABSE BADI GALTI

Trailing Stop Loss

Kaise Kaam Karta Hai?:
• Entry: ₹2,500
• Initial SL: ₹2,450 (2%)
• Price ₹2,600 ho jaaye:
• → Trailing SL: ₹2,540 (2% below ₹2,600)
• → Profit locked: ₹40/share
• Price ₹2,700 ho jaaye:
• → Trailing SL: ₹2,640 (2% below ₹2,700)
• → Profit locked: ₹140/share
• Price ₹2,650 ho jaaye:
• → SL hit at ₹2,640
• → Exit with ₹140/share profit

Trailing SL = Profit lock karte jaao as price moves in your favor.

Stop Loss by Trading Style

Ye chaar baatein dhyaan mein rakho:
• Intraday — SL Type: Fixed/ATR, SL Size: 0.5-1%
• Swing — SL Type: Support-based, SL Size: 2-3%
• Positional — SL Type: Support/ATR, SL Size: 3-5%
• Long-term — SL Type: 200 DMA, SL Size: 8-10%

Common Stop Loss Mistakes

No Stop Loss

"SL lagane se trigger ho jaata hai" — Bina SL ke ek trade poora account kha sakta hai.

Moving Stop Loss (Away from Entry)

"SL thoda aur neeche rakh deta hoon" — Ye loss badhata hai. SL sirf FAVOUR mein move karo (trailing).

Too Tight Stop Loss

0.2% SL rakhoge toh normal noise mein trigger ho jayega. Stock ka volatility consider karo.

Emotional Stop Loss

"Abhi nahi bechunga, wapas aa jayega" — SL hit = exit. No negotiation.

Round Number Stop Loss

₹2,500 pe SL lagaya → sabka SL wahan hai → stop hunt ho sakta hai. Thoda below round number rakhao (₹2,480).
