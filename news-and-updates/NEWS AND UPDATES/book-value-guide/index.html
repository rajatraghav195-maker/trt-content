Book Value Kya Hai? Hindi Guide

Book value kya hai, PB ratio kaise use karein, book value vs market value — complete Hindi guide.

Published by The Retail Trader · AUG 02, 2026 · Features

Book value kya hai, PB ratio kaise use karein, book value vs market value — complete Hindi guide.

Book Value Kya Hai?

Book value = Company ka net worth per share — yaani agar company aaj band ho jaaye toh har shareholder ko kitna milega.

Book Value = (Total Assets - Total Liabilities) / Total Shares

Book Value vs Market Value

Ye chaar baatein dhyaan mein rakho:
• What it is — Book Value: Accounting value, Market Value: Market price
• Decided by — Book Value: Financial statements, Market Value: Demand/supply
• Changes — Book Value: Quarterly, Market Value: Real-time
• Use — Book Value: Fundamental analysis, Market Value: Trading

PB Ratio (Price to Book)

Ye chhe baatein dhyaan mein rakho:
• PB Ratio = Market Price / Book Value
• Example:
• Market Price: ₹500
• Book Value: ₹250
• PB Ratio: 2.0

Ye chaar baatein dhyaan mein rakho:
• < 1 — Undervalued (trading below book value)
• 1-2 — Fair value
• 2-3 — Slightly overvalued
• > 3 — Overvalued (unless high ROE)

PB Ratio by Sector

Ye paanch baatein dhyaan mein rakho:
• Banking — 1.5-2.5
• IT — 5-10
• FMCG — 8-15
• Infrastructure — 1-3
• PSU — 0.5-1.5

When to Use PB Ratio

Good For:
• Banking stocks (asset-based)
• Capital-intensive industries
• Comparing similar companies

Not Good For:
• IT companies (asset-light)
• FMCG (brand value not in book)
• Service companies

Cheat Sheet

Ye baatein dhyaan mein rakho:
• 📌 BOOK VALUE
• 📊 Net worth per share
• 📊 (Assets - Liabilities) / Shares
• PB RATIO:
• 📊 Market Price / Book Value
• 📊 < 1 → Undervalued
• 📊 1-2 → Fair value
• 📊 > 3 → Overvalued
• PB BY SECTOR:
• 📊 Banking: 1.5-2.5
• 📊 IT: 5-10
• 📊 FMCG: 8-15
• 📊 PSU: 0.5-1.5
• USE PB FOR:
• ✅ Banking stocks
• ✅ Capital-intensive industries
• ✅ Comparing similar companies
• DON'T USE PB FOR:
• ❌ IT companies (asset-light)
• ❌ FMCG (brand value)
• ❌ Service companies
