Portfolio Tracker Kya Hai?

Portfolio tracker ek tool hai jo tumhare saare investments ek jagah dikhata hai — stocks, mutual funds, gold, everything.

Best Portfolio Trackers India

1. INDmoney:
• Price: Free
• Features: Stocks, MF, FD, NPS, EPF, PPF tracking
• Auto-sync: Zerodha, Groww, etc.
• Best for: All-in-one tracking

2. Groww:
• Price: Free
• Features: Stocks + MF portfolio
• Auto-sync: Groww investments only
• Best for: Groww users

3. Zerodha Console:
• Price: Free
• Features: Stocks + MF + P&L
• Auto-sync: Zerodha only
• Best for: Zerodha users

4. MProfit:
• Price: Free (basic), ₹2,000/year (premium)
• Features: Stocks, MF, F&O, commodities
• Auto-sync: Multiple brokers
• Best for: Active traders

5. Google Sheets:
• Price: Free
• Features: Custom tracking
• Auto-sync: Manual
• Best for: DIY investors

What to Track

Ye chhe baatein dhyaan mein rakho:
• Total investment — Kitna lagaya hai
• Current value — Abhi kitna hai
• Returns (XRR) — Actual returns (time-weighted)
• CAGR — Annual return
• Asset allocation — Equity/debt/gold ratio
• Dividends — Passive income

XIRR vs CAGR

Ye do baatein dhyaan mein rakho:
• CAGR — Lump sum investment
• XIRR — SIP (multiple transactions)

XIRR is better for SIP investors — accounts for timing of each investment.

Portfolio Review Frequency

Ye paanch baatein dhyaan mein rakho:
• SIP in MF — Quarterly
• Direct stocks — Monthly
• F&O — Daily
• Gold/SGB — Half-yearly
• PPF/EPF — Yearly
